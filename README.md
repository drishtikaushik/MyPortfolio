# Drishti Kaushik — Portfolio

A single-page, scroll-driven portfolio site. Instead of the usual resume-card
layout, the page tells a short first-person story in chapters, with one
continuous illustrated scene running behind it that reacts to how far you've
scrolled.

## How it works

- **One file, no build step.** Everything — markup, styles, and behavior —
  lives in `portfolio.html`. Open it directly in a browser, or upload it as-is
  to any static host.
- **The background scene** is a single SVG generated by JavaScript at load
  time. It spans the full height of the page and includes:
  - a color wash that shifts from pale dawn at the top to night ink at the
    bottom, tying the whole scroll together
  - one winding trail running top to bottom
  - a glowing marker that travels along the trail in sync with your scroll
    position, switching to a warmer "lantern" color once it crosses into the
    night section
  - one line-art icon per chapter (magnifying glass, graduation cap, stacked
    cards, a grid of blocks, connected nodes, a compass, an envelope), placed
    on the side opposite that chapter's text panel
- **The chapters** are plain HTML sections, each holding one text panel that
  fades and slides into view via `IntersectionObserver` as you scroll past it.
- The scene is rebuilt on window resize and once fonts finish loading, so it
  stays aligned with the actual page layout on any screen size.

## Running it locally

No install, no dependencies. Just open the file:

```
open portfolio.html      # macOS
start portfolio.html     # Windows
```

Or serve it locally if you prefer:

```
python -m http.server
```

then visit `http://localhost:8000/portfolio.html`.

## Hosting it

Because it's a single static HTML file, it can go straight onto:

- **GitHub Pages** — push it to a repo, rename it to `index.html`, enable
  Pages in the repo settings
- **Vercel / Netlify** — drag-and-drop deploy, no config needed
- Any basic static host or shared hosting plan

## Customizing

Everything is inside `portfolio.html`, organized top to bottom:

| Section | Where to edit |
|---|---|
| Colors, fonts | CSS variables at the top of the `<style>` block (`--ink`, `--paper`, `--accent`, `--font-serif`, `--font-sans`) |
| Chapter text | The `<section class="chapter">` blocks in the HTML body |
| Which side each panel sits on | Add or remove the `reverse` class on a `<section class="chapter">` |
| Background icons | The `addIcon()` function and `iconMap` array near the bottom `<script>` |
| Sky gradient / mood | The `stops` array inside `buildScene()` |
| Trail shape | The `xUnits()` function and `WAVES` constant |
| Contact links | The `#closing` section |

## Notes

- Respects `prefers-reduced-motion` — animations and smooth scrolling are
  disabled for users who've turned that on.
- No external JS libraries — just the browser's built-in SVG, Canvas-free DOM
  APIs, and `IntersectionObserver`.
- Fonts are loaded from Google Fonts (`Fraunces` for headings, `Inter` for
  body text) via a CDN link in the `<head>`.
